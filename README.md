A traffic jam explained to a 10-year-old in two lines: a river of cars that hit a dam. Line 1 lands the picture in one vivid sentence; line 2 says honestly what the analogy maps and what it leaves out.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
